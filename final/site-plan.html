Site Plan

Site Name

"COUNTRY EXPLORER"

The name "Country Explorer" was chosen because it's simple, memorable, and clearly describes what the site does: it lets users explore and discover information about countries.

Site purpose

The "Country Explorer" website will provide a clean, fast, and user-friendly interface for users to look up and browse key information about the world's countries. The site will list countries, providing data such as flags, capital cities, population, and geographic regions drawn from the REST Countries API. Services will include the ability to filter countries and a feature for users to "save" their favorites to a personal list using localStorage.

Scenarios

  • Where can I quickly find the capital, population, and flag for all countries in South America?
  • Can I filter the countries by region and save the ones I'm interested in to a list I can check later?
